# Shuttle

SSH terminal, SFTP and FTP, a code editor and a server monitor for macOS,
Windows, Linux, iOS and Android.

**Website:** https://shuttlessh.com

## Download

Get the latest version from [Releases](https://github.com/shuttlessh/shuttle/releases/latest):

| Platform | File |
|---|---|
| macOS | `Shuttle-macos.dmg` |
| Windows | `shuttle-windows-x64.zip` |
| Linux | `shuttle-linux-amd64.deb` or `.tar.gz` |
| Android | `shuttle-android-arm64-v8a.apk` |

Check a download against `SHA256SUMS` in the same release. Apps installed
from the website tell you when a new version is out (Settings → About →
Updates).

## Problems and ideas

Open an [issue](https://github.com/shuttlessh/shuttle/issues). Please
include the app version (Settings → About), your system, and what you did.
Never paste passwords, private keys or license keys.
